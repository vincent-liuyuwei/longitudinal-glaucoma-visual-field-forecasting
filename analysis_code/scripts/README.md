# Public-facing scripts

These scripts have a relatively self-contained purpose and are easier to inspect than the supporting local tools. They are included to show how the visual-field layouts and fixed regional mapping were represented.

| File | Purpose |
|---|---|
| [`generate_vf_layout_figures.py`](generate_vf_layout_figures.py) | Generates explanatory layouts for the public 52-point UWHVF example and the native 59-point Bern/GRAPE six-region mapping. |

The generated figures are methodological illustrations. They do not contain patient measurements.
