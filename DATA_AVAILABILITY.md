# Data availability and privacy boundary

The Bern and GRAPE cohorts used in the thesis are not redistributed here. This public repository contains no raw clinical records, patient identifiers, raw fundus photographs, patient-eye-level exports, learned model weights, cached image embeddings, or institutional consent forms.

The public release contains selected source code, cleared teaching notebooks, architecture schematics, and aggregate result visualisations. The analysis scripts document the workflow but require an authorised local data environment to run. Paths, outputs, caches, and configuration must be supplied locally by an approved user.

The repository is intended for research communication and PhD-application review. Before adding any new data-derived file or changing the scope of the release, confirm permission with the supervisor, University of Bern, and the relevant cohort/data owners. In particular, do not add individual qualitative prediction cases merely because they contain no visible patient name.
