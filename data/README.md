# Data access boundary

No clinical dataset is included in this public repository. The thesis used restricted Bern and GRAPE cohort data under institutional and cohort-specific access conditions; those source records are not redistributable here.

## Included

- this explanation of the data boundary;
- code that documents the expected analysis workflow;
- aggregate, non-identifying figures in [`../figures/results/`](../figures/results/).

## Excluded

- raw clinical records or patient identifiers;
- patient-eye-level tables, prediction exports, or derived files that could be linked back to an individual;
- raw or processed fundus images and cached image embeddings;
- cohort spreadsheets, local data splits, and other restricted source files.

If you have authorised access and want to run the workflow, provide the data and configuration locally. Never commit those files to a public fork. Before adding any data-derived artefact, confirm permission with the supervisor, the University of Bern, and the relevant cohort or data owners.
